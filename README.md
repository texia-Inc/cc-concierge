# cc-concierge

中小企業の社長のための、Claude Code 仮想エージェントチームプラグイン。
**コンシェルジュ**が窓口となり、業種別の担当チームに依頼を振り分けます。

## こんな方に

- **複数の役割を一人で兼任している社長**（経営・営業・経理・人事ぜんぶ）
- 月次の数字確認が後手に回りがち
- 相談相手がおらず、意思決定が孤独
- 「営業」「経理」「人事」を一人で頭の中で切り替えるのに疲れた

## 特徴

- 🎩 **コンシェルジュが窓口**：すべての依頼はまず受付け、担当者に振り分け
- 🏭 **業種別テンプレ（5業種）**：飲食店・美容室・建設業・製造業・小売 + 汎用
- 📁 **完全部署型**：各担当者が独立フォルダを持ち、専門領域ごとに記録が蓄積
- 📊 **月次の数字確認を組み込み**：月初に経理担当が必ず先月の数字を促す
- 🗣 **多視点の議論**：意思決定は複数担当者の意見を併記、社長が判断
- 🧠 **控えめで丁寧な口調**：仰々しい敬語は使わず、業務的だが温かみのある対応

## インストール

Claude Code 内で:

```
/plugin marketplace add texia-Inc/cc-concierge
/plugin install concierge@cc-concierge
```

## 使い方

任意のディレクトリで `/concierge` を実行すると、初回はオンボーディングが始まります。

### オンボーディング（3問）

1. **業種**は何ですか？（飲食店 / 美容室 / 建設業 / 製造業 / 小売 / その他）
2. **従業員数**の規模は？（1〜5名 / 6〜20名 / 21名以上）
3. 直近で**一番困っていること**は？（売上・集客 / 人・採用 / 資金・経理 / 時間・業務効率）

回答に応じて担当者チームが自動編成され、`.concierge/` ディレクトリが生成されます。

### 2回目以降

```
/concierge
```

> コンシェルジュ：お疲れさまです。本日は3件のご依頼をお預かりしています。

そのまま自然言語で依頼や相談ができます:
- 「採用、月50万かけてもいい？」
- 「先月の売上、整理したい」
- 「次の打ち合わせの議事録、用意して」

## 生成されるディレクトリ構造

```
.concierge/
├── CLAUDE.md                ← チーム全体の運営ルール
├── company-info.md          ← 業種・規模・悩みのプロフィール
├── concierge/               ← 窓口・横断記録
│   ├── CLAUDE.md
│   ├── inbox/  todos/  notes/
├── [業種別担当者]/           ← 業種に応じて編成
│   ├── CLAUDE.md
│   └── inbox/  todos/  notes/
└── finance/                 ← 経理担当
    ├── CLAUDE.md
    ├── inbox/  todos/  notes/
    └── monthly/             ← 月次KPI（YYYY-MM.md）
```

## 業種別のチーム編成

| 業種 | 担当チーム |
|---|---|
| **飲食店** | ホール責任者 / キッチン責任者 / 仕入担当 / 経理 |
| **美容室** | スタイリスト統括 / レセプション / 経理 / マーケ |
| **建設・工務店** | 現場監督 / 施工管理 / 営業 / 経理 |
| **製造業** | 生産管理 / 品質管理 / 営業 / 経理 |
| **小売・EC** | 店舗運営 / 仕入 / 経理 / マーケ |
| **その他（汎用）** | 営業 / 経理 / 人事 / マーケ |

業種別のKPIは `.concierge/CLAUDE.md` の「主要KPI」を参照。月初にコンシェルジュが促してくれます。

## 担当者の追加

オンボーディング時のチーム以外にも、必要に応じて追加できます。

```
あなた: 顧問担当を追加して
コンシェルジュ: 顧問担当を追加いたしました。専門外の質問の一次対応ができます。
```
